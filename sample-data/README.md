# Échantillon synthétique

Le fichier `F_CLIENT_SAMPLE.txt` illustre la structure multi-format utilisée dans le projet.

Toutes les identités, coordonnées et clés ont été créées uniquement pour cette démonstration. Elles ne proviennent pas du fichier d’origine.

L’échantillon contient volontairement plusieurs cas de qualité :

- deux comptes et deux clients valides ;
- un compte avec un cabinet non autorisé ;
- un client rattaché à un compte absent ;
- un email valide et un email invalide ;
- deux types de téléphone pour un même client ;
- une adresse rattachée à un client absent.

Le pied du fichier indique le nombre total de lignes, en incluant l’en-tête et le pied.
